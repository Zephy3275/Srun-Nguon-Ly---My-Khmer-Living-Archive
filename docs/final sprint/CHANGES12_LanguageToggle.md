# CHANGES12 - Language toggle (Week 13, final sprint)

A three-way language switch in the header: **EN + ខ្មែរ** (the default, the site as it was), **EN** (English only) and **ខ្មែរ** (Khmer only). No new package, no database change. Built in small steps; each one is tested by the student before the next.

## Where the Khmer came from

- 2026-11-21: the AI counted every user-visible English string with no Khmer: **151 strings**, used in about 200 places. The list, with an ID per string, is in `../Week13/Language_Toggle_Files/Khmer_Strings_For_Gemini.md` (outside the repo).
- The student gave the list to **Gemini 3.1 Pro**, which drafted the Khmer (`khmer_strings_translated.md`, same folder). The AI checked that all 151 IDs came back with the English unchanged and `{count}` / `{query}` kept.
- The student reads and corrects every Khmer string. The AI wrote none of it.
- The student's 16 earlier Khmer strings are kept as written, with two changes the student chose: the RETURN button now says បញ្ជូនត្រឡប់មកវិញ, and the two save notices now name the menu «ធាតុរបស់ខ្ញុំ», so it matches the menu.

## How it works

- **The choice** lives in a cookie called `lang`: `both`, `en` or `km`. No cookie, or an unknown value, means `both`.
  - A cookie, because most pages are built on the server, and the server can read a cookie on every request.
  - It holds only the language, nothing about the user.
- **`utils/lang.js`** (`getLang()`): the server reads the cookie. Each page calls it and passes `lang` down to its components as a prop.
- **`utils/strings.js`**: every string by ID, with `en` and `km`. `t(lang, id, vars)` returns the Khmer in Khmer-only mode, and the English otherwise.
  - A string with no Khmer falls back to English.
  - `{count}` and `{query}` are filled in from `vars`.
  - The file was generated by a script from Gemini's file, so no Khmer was retyped.
- **`components/LangSwitch.js`**: the three buttons. A press saves the cookie for a year, then calls `router.refresh()`. That asks the server to redraw the page in the new language and keeps what is on screen, such as a typed search.
- **`app/layout.js`**: `<html lang="km">` in Khmer-only mode, `"en"` otherwise.
- **`app/globals.css`**: one rule, `:lang(km) { letter-spacing: 0 !important; }`. Letter spacing pulls Khmer letter stacks apart, and the header's spaced capitals would do that to Khmer.
